# HSP 命令実装ロードマップ

HSPPP は HSP (Hot Soup Processor) 互換の C++23 ライブラリです。本ロードマップは HSP 命令／関数／システム変数の実装状況・優先度・対応方針を一覧化した内部開発資料であり、外部コントリビュータの参考資料として公開しています。

> このドキュメントは開発記録であり、実装状況は進捗に応じて更新されます。最新の API 仕様は [API リファレンス](/HSPPP_Lib/api/) を参照してください。

## 凡例

### 実装ステータス

| 記号 | 意味 |
|------|------|
| ✓ | 実装済み |
| ○ | 実装予定 |
| △ | 一部実装 / 検討中 |
| × | 不要（ライブラリの方針外） |
| - | 保留 |

### 優先度

| 記号 | 意味 |
|------|------|
| `[P1]` | 最優先（基幹機能 / GUI 確認に必須） |
| `[P2]` | 高優先度（基本機能） |
| `[P3]` | 中優先度（便利機能） |
| `[P4]` | 低優先度（拡張機能） |
| `[--]` | 不要 |

## 不要機能（ライブラリ方針外）

### プリプロセッサ命令 [--]

× すべてのプリプロセッサ命令

- **理由**: C++ コンパイラのプリプロセッサを使用 (`#include`, `#define`, `#ifdef` 等の C++ 標準を使用)。

### DLL / COM 関連 [--]

| 命令 | 種別 |
|------|------|
| `#uselib`, `#func`, `#cfunc` | 外部 DLL 関連 |
| `#usecom`, `#comfunc` | COM 関連 |
| `mcall`, `callfunc`, `libptr` | 外部呼び出し関連 |

- **理由**: C++ の標準的な DLL/COM アクセス手法を使用する。

### モジュール機能（HSP 独自仕様） [--]

× `#module`, `#global`, `#modinit` 等

- **理由**: C++ のクラス・名前空間を使用する。

### 変数型宣言（HSP 独自仕様） [--]

× `#var`, `#varint`, `#varstr` 等

- **理由**: C++ の型システムを使用する。

### 実行時パッキング [--]

× `#pack`, `#epack`, `#packdir` 等

- **理由**: ビルドシステムで対応する。
